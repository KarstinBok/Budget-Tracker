# Working on this repo

## Shipping changes

When a change is finished and tested, always open a pull request into `main` and merge it straight away, without asking first. This applies to every change in this repo.

- Target `main` (the Android build and recent PRs use it).
- If `main` has moved on and the PR has conflicts, merge `main` into the branch, resolve the conflicts, push, then merge.
- Afterwards, report the PR link and that it was merged.
